# About me

I come to technical writing from both literature and computer science. Since 2018 I've written and translated books,
and before that I spent years building, testing and fixing computers and software.

On the technical side, I've worked as an IT technician fixing hardware and Windows problems,
built and published an Android app, created websites from scratch in HTML and CSS,
tested software for uTest, and volunteered on open source localization, translating the Tuta email app from English to Greek. 
I'm comfortable in Postman, familiar with REST APIs, and I read code well enough to document it accurately.

On the writing side, I've published three books: translations of C. P. Cavafy, with historical commentary,
and K. G. Karyotakis, with notes; and a philosophical anthology with a bibliography of 400+ sources.
I write technical content with the same care.

You can see my literary work at [Fragments of Freedom](https://author.babisdanias.com).

Based in Thessaloniki, Greece. Available to start remotely immediately;
can relocate to Helsinki on the timeline the role requires.
